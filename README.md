## Marque

- **Nom** : NEXUS AI
- **Positionnement** : plateforme SaaS d'automatisation marketing par IA
- **Angle** : "L'IA Chercheur" — l'IA fait le travail de recherche/exécution pendant que le fondateur se concentre sur le revenu
- **Cible** : entrepreneurs francophones (France, Belgique, Suisse romande), solo-founders et petites équipes
- **Ton** : direct, sans jargon corporate, orienté résultat. Phrases courtes, accroches punchy (cohérent avec le contenu TikTok/Instagram @nextgen.ai.make, @jnto.biz)
- **Langue** : français (registre légèrement québécois/familier accepté), avec variante anglaise si besoin

## Registre par projet

- **Dashboard (app-nexusai.com)** → registre **Product**. L'app doit être fluide et familière pour des gens qui utilisent déjà Linear, Stripe Dashboard, Notion. Priorité : clarté, hiérarchie, confiance.
- **Site vitrine / landing** → registre **Brand**. Doit se démarquer, pas ressembler à un template SaaS générique. Priorité : impact visuel, conversion, mémorabilité.

## Palette

| Rôle | Couleur | Hex |
|---|---|---|
| Fond principal (dark) | Navy profond | `#0a0a1a` |
| Accent primaire | Violet | `#7c5cfc` |
| Accent secondaire | Cyan | `#00d4ff` |
| Dégradé signature | Violet → Cyan | `#7c5cfc → #00d4ff` |
| Texte sur fond sombre | Blanc cassé | `#f5f5f7` |
| Texte secondaire | Gris clair | `#a1a1aa` |

Règle : le dégradé violet→cyan est la signature de marque — l'utiliser avec parcimonie (CTA, accents, wordmark), jamais en fond plein sur de larges zones. Éviter tout dégradé violet-bleu qui ne suit pas exactement ces deux teintes (ça devient le "slop" générique que justement on veut éviter).

## Typographie

- Pas d'Inter par défaut partout — choisir une police avec un peu plus de caractère pour les titres (ex. une sans-serif géométrique ou une display font distinctive), Inter ou système en corps de texte seulement si besoin de lisibilité pure sur le dashboard.
- Hiérarchie claire : titres impactants, corps de texte sobre.

## Composants

- Éviter les "cards dans des cards" et les tuiles d'icônes arrondies au-dessus de chaque titre (anti-pattern générique IA).
- Boutons CTA : dégradé signature, coins nets ou légèrement arrondis (pas de pilule à outrance).
- Sur le dashboard : densité d'information assumée (façon Linear/Stripe), pas d'espace vide gratuit.
- Sur le site vitrine : plus de respiration, sections avec du contraste fort entre zones claires/sombres.

## Pricing (référence)

3 tiers à afficher clairement différenciés visuellement (pas juste 3 cards identiques avec un badge "populaire") :
- **Starter** — 27€/mois
- **Pro** — 67€/mois (mettre en avant, c'est le tier recommandé)
- **Agency** — 147€/mois

## Anti-références

Ne pas ressembler à : templates SaaS génériques type "AI startup Framer template", dégradés violet-bleu non maîtrisés, gris sur fond coloré, icônes dans des cercles au-dessus de chaque feature.

## Inspirations (pour ton style, pas pour copier)

Linear (clarté produit), Stripe (confiance/pro), un soupçon d'énergie créateur de contenu (pas trop corporate — NEXUS AI reste porté par un fondateur visible sur les réseaux).
